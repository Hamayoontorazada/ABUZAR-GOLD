نسخه آزمایشی سازگار با صفحه موبایل آیفون.
در آیفون فایل ZIP را در Files باز کنید، سپس index.html را باز نمایید. اطلاعات فقط در همان مرورگر/دستگاه ذخیره می‌شود. برای استفاده واقعی و همگام‌سازی با لپ‌تاپ هنوز توسعه و آزمایش امنیتی لازم است. از اطلاعات آزمایشی استفاده کنید و از بخش پشتیبان‌گیری نسخه JSON بگیرید.
